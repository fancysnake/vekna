# Reborn — the pivot to rituals and casts

Ideas, not a plan. One file is one release's worth of work; nothing here says
when, in what order, or against which version — those answers live in
`CHANGELOG.md` after the fact, and nowhere before it.

[common.md](common.md) is the shared context every file here assumes: premise,
vocabulary, ritual model, process model, layering, wire protocol, components,
configuration, CLI surface, resolved decisions, and what is not planned. It is
the only file the others point at.

The rest of the directory is the ideas. Shipped ones move to
[`../done/reborn/`](../done/reborn/) and stop being edited.

Two neighbouring tracks, same rules: [`../eye/`](../eye/README.md), the surfaces
that watch, and [`../hand/`](../hand/README.md), the engine's acting half.
