# Reborn — the pivot to rituals and casts

Ideas, not a plan. They live as GitHub issues under the
[Reborn milestone](https://github.com/fancysnake/vekna/milestone/1), sized `S` /
`M` / `L` / `Epic`; nothing there says when, in what order, or against which
version — those answers live in `CHANGELOG.md` after the fact, and nowhere
before it.

[common.md](common.md) is the shared context every issue here assumes: premise,
vocabulary, ritual model, process model, layering, wire protocol, components,
configuration, CLI surface, resolved decisions, and what is not planned. It is
the only file the issues point at.

Shipped ones close, and `CHANGELOG.md` is what records them.

Two neighbouring tracks, same rules: [`../eye/`](../eye/README.md), the surfaces
that watch, and [`../hand/`](../hand/README.md), the engine's acting half.
